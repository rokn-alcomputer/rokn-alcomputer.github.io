شروحات برامج الكمبيوتر خطوة بخطوة

الرئيسيةDeep Freezeويندوز 11تسريع ويندوزفلاشة بوتأمان Windowsنسخ احتياطيريست ويندوزمساحة الهاردإصلاح التشغيلاسطوانة ويندوزقناة يوتيوب

فضي مساحة على الهارد في ويندوز 10 و11 بأدوات مايكروسوفت نفسها (بدون برامج)

لو الشرح فادك: لايك وشير للفيديو، واشترك في القناة.

اشترك في القناة

شوف مين بياكل المساحة

  1. افتح File Explorer ثم This PC: هتشوف كل درايف وكام فاضي فيه.
  2. من Settings ثم System ثم Storage: هتشوف البرامج والملفات المؤقتة وملفات النظام وكل حاجة واخدة كام.

Storage Sense (حس التخزين)

  1. Settings ثم System ثم Storage، وخلي Storage Sense على On.
  2. اختار كل قد إيه تشتغل: لما المساحة تقل، أو كل أسبوع، أو كل شهر.
  3. اختار بعد كام يوم يتمسح اللي في سلة المحذوفات.
  4. خد بالك: بيشتغل على درايف النظام (C) بس، ولازم تكون داخل بحسابك ومتصل بالنت.
  5. إعداد فولدر Downloads مش هيتلمس غير لو إنت فعّلته، فلو شغّلته خلي المدة طويلة أو اختار Never.

الملفات المؤقتة وCleanup recommendations

  1. Settings ثم System ثم Storage ثم Temporary files، اختار اللي عايزه ثم Remove files.
  2. جواها Previous Windows installation: لو مسحتها مش هتقدر ترجع للنسخة القديمة، والمسح مابيترجعش.
  3. Cleanup recommendations بتعرضلك ملفات مؤقتة وملفات كبيرة أو مش مستخدمة وملفات متزامنة مع السحابة وبرامج مش بتستخدمها، وجنب كل حاجة المساحة اللي هتتوفّر.

ويندوز 10: Disk Cleanup

  1. اكتب في البحث disk cleanup واختار الأداة.
  2. اختار الدرايف، وعلّم على أنواع الملفات، ثم OK.
  3. لو عايز ملفات النظام كمان: Clean up system files.

أكبر الملفات وOneDrive

  • في الفولدرات اللي فيها صور وفيديو وتنزيلات: View ثم Details، وبعدين Sort by ثم Size، وهتلاقي أكبر الملفات فوق.
  • انقلها لهارد خارجي أو فلاشة، أو امسحها، وبعدين فضّي سلة المحذوفات.
  • OneDrive Files On-Demand بيسيب ملف صغير مكان الملف الكبير ويفتحه وقت ما تحتاجه، وده مش بيمسح حاجة. أي ملف عليه Always keep on this device مش بيتأثر.
  • عشان المشكلة ماترجعش: Advanced storage settings ثم Where new content is saved، واختار درايف تاني للملفات الجديدة.

نصائح

  • سيب مساحة فاضية على C: قلة المساحة بتبطّأ الجهاز وتمنع تحديثات ويندوز.
  • اقفل البرامج المفتوحة قبل تنضيف الملفات المؤقتة.
  • لو المساحة بتنقص لوحدها من غير سبب، اعمل فحص بـ Windows Security.
  • دعم ويندوز 10 خلص في 14 أكتوبر 2025، فحدّث لويندوز 11 لو تقدر.
